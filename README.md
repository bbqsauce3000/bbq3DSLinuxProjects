## Scripts/Utilities for 3DS Linux!

Note, you need 3DSLinux, and run them on 3DSLinux to function (*duh*)

You then copy project folder you want to run, and execute it on the 3DS. I would recommened setting up an FTP server to save your sanity! It is much faster than taking your SD card out and putting it back in over and over.

Much love to [3dslinux.org.](https://3dslinux.org/)
Note that this repo is not endorsed by the 3DSLinux dev team.
